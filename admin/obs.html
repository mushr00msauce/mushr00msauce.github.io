Cloud OBS slots

Backup OBS for the Mushbox family. Each slot is its own desktop with its own OBS, scenes and stream key.

Using a slot
  1. Click a slot. The Cloudflare login you used for this page covers all four.
  2. Enter that slot's login once and let the browser save it. List them any time with obsslot list.
  3. Selkies sidebar → Screen Settings → 1920×1080 → Set Manual Resolution.
  4. On weak internet: sidebar → Video Settings → lower quality/FPS. This only changes your view, not the stream.
  5. A slot that won't load is probably parked: obsslot start N over SSH.
