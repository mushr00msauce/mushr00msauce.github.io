Installing Tailscale on a Mushbox

Tailscale gives you permanent remote SSH access to any Mushbox, anywhere it travels — no port forwarding, no serveo tunnels, no waiting on hotel WiFi to cooperate. Run this once per device and it's done forever.

Account: All Mushbox devices join the same tailnet under mushboxirl@gmail.com. Always sign in with this account when approving a new device — never create a separate tailnet per box.

1 SSH into the Mushbox

Connect to the Rock 5A as you normally would — locally on the same network, or via a temporary tunnel (serveo, etc.) if it's remote and not yet on Tailscale.

2 Install Tailscale

The stock BELABOX image ships with wget, not curl — use this: 

wget -qO- https://tailscale.com/install.sh | sh

3 Bring it up and enable SSH

This starts the Tailscale connection and turns on Tailscale's built-in SSH server in one step — no separate SSH keys or passwords to manage later. 

sudo tailscale up --ssh

This prints a one-time login URL in the terminal, something like: 

https://login.tailscale.com/a/xxxxxxxxxxxx

4 Approve the device

Open that URL in any browser — phone, laptop, doesn't matter which device — and sign in with mushboxirl@gmail.com. This is the step that actually links this specific Rock 5A to the Mushbox tailnet.

First device ever added? Tailscale may show an account-creation screen instead of a login screen — that's expected the very first time only. Every device after that just needs approval.

5 Confirm it joined

Go to:

https://login.tailscale.com/admin/machines

The Mushbox should now appear in the list, identified by its system hostname.

6 Connect going forward

From any device that's also on the mushboxirl@gmail.com tailnet (see checklist below), just SSH directly using the hostname shown in the admin console: 

ssh user@<tailscale-hostname>

No tunnel, no port forwarding, no dependency on whatever WiFi the box happens to be on.

7 Checking if it's already installed

Before repeating this on a box you're not sure about, check first:

which tailscale
tailscale status
ResultMeaning
which tailscale returns nothingNot installed — run steps 2–5.
tailscale status shows a hostname/IPInstalled and connected — nothing to do.
tailscale status says logged outInstalled but not joined — just run step 3 again.
Your own devices: to actually reach a Mushbox remotely, your phone or laptop also needs the Tailscale app installed and signed into mushboxirl@gmail.com. The install on the Mushbox side is passive — it just sits there reachable. You do the connecting from your end.

Tailscale's free Personal plan covers up to 6 users and 100 devices with no speed throttling and no time limit — comfortably enough for the entire Mushbox fleet on one account with room to grow.
