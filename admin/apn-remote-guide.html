Remote APN Change

Change a streamer's cellular APN over Tailscale, no physical access needed and no laptop required on their end. Works for both the AT&T/FirstNet USB800 and the Verizon USB730L.

1. Message to send 2. Your steps Modem reference Full script
Before you touch anything — run the script with no APN argument first on whichever modem you're changing. It only reads and prints the current value; nothing is written unless you explicitly pass a new APN as the second argument. Get in the habit of checking first, every time.

Part 2

What you do

Once their link lands in your inbox.

01
Approve the device
Open the link they sent you, logged into your own Tailscale account. This adds their box to your tailnet.
02
Confirm it shows up
Check login.tailscale.com/admin/machines for the new device, note its hostname.
03
Connect
ssh
tailscale ssh user@<their-device-hostname>
04
Check which modems they actually have
Some older builds only have the USB730L, or a different mix. Don't assume.
bash
lsusb | grep -i "1410:"
Reading the output1410:9032 or 1410:9030 → USB730L present → use "usb730l" 1410:b020 → USB800 present → use "usb800" Both lines → they have one of each No lines at all → neither is currently detected — check it's plugged in
05
Confirm interface mapping
Older builds may enumerate eth1/eth2 differently — worth a sanity check.
bash
dmesg | grep -i "9032\|9030\|b020" | tail -10
06
Check if the script is already installed
bash
ls ~/scripts/change-apn.sh
If it exists, skip to step 08. If not, install it — see full script below, or run the one-shot installer in step 07.
07
Install the script (only if missing)
Paste the whole block from the Full script section below as one paste.
08
Check current APN — read only, nothing changes
bash
~/scripts/change-apn.sh usb800
~/scripts/change-apn.sh usb730l
09
Set the real APN
Replace THEACTUALAPN with the real value. Double-check it before hitting enter — this is a live write.
bash
~/scripts/change-apn.sh usb800 THEACTUALAPN
10
Verify
Rerun step 08 with no second argument — confirm the new value stuck.
11
Clean up (optional)
If this was one-off access, remove their device from your tailnet: login.tailscale.com/admin/machines → find device → remove.
Reference

Modem quick reference

USB800 — AT&T / FirstNet

Interface:
eth1
Admin gateway:
Dynamic, via ip route show dev eth1
Host header needed:
att.manager
Form field:
NetworksProfileAPN
Script keyword:
usb800

USB730L — Verizon

Interface:
eth2
Admin gateway:
192.168.2.1 (fixed)
Host header needed:
none
Form field:
NetworksFourGLTEAPN
Script keyword:
usb730l
Install

Full script — one-shot installer

Paste this entire block as a single paste on the streamer's box. Creates ~/scripts/change-apn.sh and makes it executable.

bash — full installer
mkdir -p ~/scripts
cat > ~/scripts/change-apn.sh << 'SCRIPT_EOF'
#!/bin/bash
# change-apn.sh - Remotely read or change the APN on the Mushbox's USB800 or USB730L modem
# Usage:
#   ./change-apn.sh usb800  [new-apn]     # AT&T/FirstNet modem on eth1
#   ./change-apn.sh usb730l [new-apn]     # Verizon modem on eth2
# If new-apn is omitted, just prints the current APN without changing anything.

set -e

MODEM="$1"
NEW_APN="$2"

if [ -z "$MODEM" ]; then
    echo "Usage: $0 <usb800|usb730l> [new-apn]"
    exit 1
fi

case "$MODEM" in
    usb800)
        IFACE="eth1"
        GATEWAY=$(ip route show dev "$IFACE" 2>/dev/null | grep default | awk '{print $3}')
        LOCAL_IP=$(ip route show dev "$IFACE" 2>/dev/null | grep "src" | awk '{print $NF}')
        if [ -z "$GATEWAY" ] || [ -z "$LOCAL_IP" ]; then
            echo "ERROR: Couldn't determine gateway/local IP for $IFACE. Is the modem attached to the network right now?"
            exit 1
        fi
        HOST_HEADER="att.manager"
        BASE_URL="http://$GATEWAY"
        FIELD="NetworksProfileAPN"
        COOKIE_JAR="/tmp/apn_cookies_usb800.txt"
        PAGE_FILE="/tmp/apn_usb800.html"
        ;;
    usb730l)
        IFACE="eth2"
        LOCAL_IP=$(ip -4 addr show "$IFACE" 2>/dev/null | grep inet | awk '{print $2}' | cut -d/ -f1)
        if [ -z "$LOCAL_IP" ]; then
            echo "ERROR: Couldn't determine local IP for $IFACE. Is the modem attached to the network right now?"
            exit 1
        fi
        GATEWAY="192.168.2.1"
        HOST_HEADER=""
        BASE_URL="http://$GATEWAY"
        FIELD="NetworksFourGLTEAPN"
        COOKIE_JAR="/tmp/apn_cookies_usb730l.txt"
        PAGE_FILE="/tmp/apn_usb730l.html"
        ;;
    *)
        echo "ERROR: Unknown modem '$MODEM'. Use 'usb800' or 'usb730l'."
        exit 1
        ;;
esac

echo "Modem:    $MODEM"
echo "Iface:    $IFACE"
echo "Local IP: $LOCAL_IP"
echo "Gateway:  $GATEWAY"
echo ""

HOST_ARGS=()
if [ -n "$HOST_HEADER" ]; then
    HOST_ARGS=(--header="Host: $HOST_HEADER")
fi

wget -q -T 8 -O "$PAGE_FILE" --save-cookies "$COOKIE_JAR" --keep-session-cookies \
    --bind-address="$LOCAL_IP" "${HOST_ARGS[@]}" "$BASE_URL/networks/"

TOKEN=$(grep -oP "name=\"gSecureToken\".*?value=\"\K[^\"]+" "$PAGE_FILE" | head -1)
CURRENT_APN=$(grep -oP "name=\"$FIELD\".*?value=\"\K[^\"]*" "$PAGE_FILE" | head -1)

if [ -z "$TOKEN" ]; then
    echo "ERROR: Couldn't extract security token. The modem's admin page may be unreachable or its layout changed."
    exit 1
fi

echo "Current APN: $CURRENT_APN"

if [ -z "$NEW_APN" ]; then
    echo "(No new APN given - nothing changed. Pass a value as the 2nd argument to set one.)"
    exit 0
fi

echo "Setting APN to: $NEW_APN"
echo ""

if [ "$MODEM" = "usb800" ]; then
    RESPONSE=$(wget -q -T 8 -O - --load-cookies "$COOKIE_JAR" --bind-address="$LOCAL_IP" \
        --header="Host: $HOST_HEADER" --header="Referer: http://$HOST_HEADER/networks/" \
        --post-data="${FIELD}=${NEW_APN}&NetworksProfileAuthentication=0&NetworksProfileUsername=&NetworksProfilePassword=&gSecureToken=${TOKEN}" \
        "$BASE_URL/networks/")
    if echo "$RESPONSE" | grep -q "saved successfully"; then
        echo "SUCCESS: Changes saved."
    else
        echo "WARNING: No success confirmation seen in response. Verify manually."
    fi
else
    RESPONSE=$(wget -q -T 8 -O - --load-cookies "$COOKIE_JAR" --bind-address="$LOCAL_IP" \
        --header="Referer: $BASE_URL/networks/" \
        --post-data="${FIELD}=${NEW_APN}&NetworksOtherAPN=&gSecureToken=${TOKEN}" \
        "$BASE_URL/networks/")
    echo "$RESPONSE" > "$PAGE_FILE"
    APPLIED_APN=$(grep -oP "name=\"$FIELD\".*?value=\"\K[^\"]*" "$PAGE_FILE" | head -1)
    if [ "$APPLIED_APN" = "$NEW_APN" ]; then
        echo "SUCCESS: APN now shows as '$APPLIED_APN'."
    else
        echo "WARNING: Page shows APN as '$APPLIED_APN', expected '$NEW_APN'. Verify manually."
    fi
fi
SCRIPT_EOF
chmod +x ~/scripts/change-apn.sh
If ~/scripts/change-apn.sh gives "Permission denied" even after chmod +x, that box's home directory may have noexec set. Just run it as bash ~/scripts/change-apn.sh usb800 instead — works identically, just invoked through the interpreter directly.
