Flip an Upside-Down Camera with !flip

If your camera is mounted upside down on the rear-view mirror and you sometimes pull it off to hold it upright, a !flip chat command lets you (or your mods) switch the picture without touching OBS. This guide covers the setup and the one OBS setting that makes it work correctly.

The common problem: you add the command, run it, and the feed jumps off-screen, goes black, or lands in a corner. The command is fine. OBS is flipping the image around the wrong point.

Why it breaks

OBS flips a source by making its size negative (for example, -1920 × -1088). It mirrors the image around the source's Positional Alignment point, and by default that point is the top-left corner.

Flipping around the corner swings the whole picture up and to the left, off the canvas. Setting the alignment to center makes the image flip in place.

Part 1: Set up the command in Streamer.bot

  1. Go to Actions & Queues → Actions, right-click, and choose Add. Name it Flip.
  2. In the Triggers panel, right-click and choose Core → Commands → Command Triggered. Create a command called !flip (or pick an existing one).
  3. In the Sub-Actions panel, right-click and choose OBS Studio → Sources → Flip Source.
  4. Pick your OBS connection, the scene (for example, IRL), and the source (for example, Mushbox).
  5. Set the direction to Both (horizontal and vertical). A camera mounted upside down is flipped both ways, not just mirrored.
  6. Click OK, then Save at the top of Streamer.bot.

Tip: If you only want mods to use it, open the command under Commands and restrict permissions to moderators and the broadcaster.

Part 2: Fix the source in OBS

You only need to do this once per scene that uses the camera.

Live right now? Turn on Studio Mode first. You edit the preview on the left, and nothing changes on stream until you click Transition.

  1. In the Sources dock, right-click your camera source and choose Transform → Edit Transform (or select it and press Ctrl + E).
  2. Under Alignment (the small 3×3 grid next to Rotation, at the top right), click the center square:
  3. Set Position X to 960 and Y to 540 for a 1920×1080 canvas. If OBS shows negative numbers like -960 and -540, delete the minus signs.
  4. Leave Width and Height as they are. If the camera is mounted upside down, they will be negative, and that's correct.
  5. Leave the Bounds settings alone. Don't click Reset, because it clears the flip and the bounds.
  6. Click Close. If you're in Studio Mode, check that the preview looks right, then click Transition.

What it should look like

SettingValue
Position960 / 540
Alignment (top)Center
Size-1920 / -1088 when mirror-mounted (any positive or negative size is fine)
BoundsFit, 1920 × 1080, centered
Rotation0.00°

Part 3: Test it

  1. Type !flip in chat. The picture should switch orientation in place, without sliding or going black.
  2. Type !flip again. It should switch back.

How it's used on stream

Camera positionWhat to do
Mounted upside down on the mirrorThe normal state. The picture shows right side up.
Pulled off and held uprightRun !flip once.
Put back on the mirrorRun !flip again.
Picture is upside down by mistakeRun !flip one more time. It's a toggle.

Troubleshooting

SymptomFix
Preview goes black after the flipThe position is negative or the alignment isn't centered. Redo Part 2, steps 2 and 3.
Image slides to a corner when flippedThe alignment is still top-left. Set it to center in Edit Transform.
Image is mirrored but still upside downThe flip direction is set to Horizontal only. Change it to Both in the Flip Source sub-action.
Works in one scene but not anotherEach scene keeps its own transform. Repeat Part 2 in every scene that shows the camera.
Nothing happens at allCheck that Streamer.bot shows OBS as Connected, the right connection is selected in the sub-action, and the source name matches exactly.
You clicked Reset by accidentSet Bounds back to Fit at 1920 × 1080, set alignment to center and position to 960 / 540, then run !flip to get back to the mirror orientation.
