This is a recurring $10/month charge through GitHub Sponsors — not a one-time payment. It's paid through GitHub, using your own billing info on file.

The steps

Go to the sponsor page

Head to github.com/sponsors/rationalsa — that's rationalirl, the developer behind Belabox. You'll need a GitHub account first if you don't already have one.

Select the $10/month tier$10/mo

This is the tier that unlocks the SRT + SRTLA relay servers — the part your Mushbox rig actually needs to bond and stream. Don't pick the $5 tier; it only gets you remote management, not the relay.

Complete the sponsorship

Confirm it as a monthly recurring donation and pay through GitHub, using your own card/billing info on file.

Wait for account provisioning

Belabox cloud access is tied to your GitHub login and usually shows up shortly after sponsoring. It's not always instant, so don't worry if it takes a bit.

Send me your login

Once you've sponsored and the account is active, send me your GitHub username and password. I'll log in to cloud.belabox.net and handle the relay setup on your rig from there.
