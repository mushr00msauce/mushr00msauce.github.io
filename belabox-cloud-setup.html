Setting up BELABOX Cloud

Get your BELABOX Cloud account running so I can connect your Mushbox to the SRT/SRTLA relay — the ingest your rig bonds through

relay ready
Before you start Pick a password you don't mind sharing with me. BELABOX Cloud logs in through GitHub, so you'll create a GitHub account and send me that login during setup. Don't reuse a password from your email, bank, or anything else. When I'm done, you change it and I'm locked out.

You'll need an email you can check during setup and about $10/month, paid to BELABOX either as a monthly GitHub sponsorship or a prepaid voucher.

Only share your login with meI'll only ever ask for this in a DM from mushr00msauce, after you've ordered a Mushbox. If anyone else asks for your GitHub or BELABOX login, it isn't me.

The steps

Create a GitHub account

Go to github.com/signup and enter your email, the shareable password, and a username. GitHub emails you a code to confirm your address. Enter it to finish.

Already have a GitHub account? You can use it, but only if you're OK temporarily sharing its password.

Pay at the $10 level$10/mo

The $10 level unlocks the SRT + SRTLA relay servers — the part your Mushbox actually needs to bond and stream. Don't pick $5; it only gets you remote management, not the relay. Choose one way to pay:

Option A · GitHub Sponsors (monthly). Signed into GitHub, go to github.com/sponsors/rationalsa — that's rationalirl, the developer behind Belabox. Pick the $10 monthly tier and pay with your own card. It renews every month until you cancel.

Option B · Prepaid voucher. At shop.belabox.net, choose the $10/month value and 1, 2, 3, 6, or 12 months. The code is emailed to you, usually within 12 hours but it can take up to 48. Vouchers can't be refunded once the code is sent.

Log in to BELABOX Cloud

Go to cloud.belabox.net, tap Login / register with Github, and approve the request GitHub shows you.

Bought a voucher? Enter the code on that page. Sponsored? Access usually shows up shortly after, but it isn't always instant, so give it a bit if it's not there yet.

Send me your login

DM me your GitHub username and password on Discord. Never post them in a public channel. I'll log in and set up the relay on your rig from there.

Keep your email handy while I do. GitHub often sends a sign-in code when someone logs in from a new computer, and I'll ask you to read it to me. Don't turn on two-factor authentication until I'm done.

Change your password

Once I tell you your Mushbox is linked, change your password on GitHub: profile picture → Settings → Password and authentication. This is a good time to turn on two-factor too.

Your Mushbox stays connected after the change. Nothing on the rig needs to be redone.
